# Student Management System

A console-based Student Management System built using Python and MySQL following a professional layered backend architecture.

## 🚀 Features

- Add Student
- MySQL Database Integration
- Layered Architecture
- Object-Oriented Programming (OOP)
- Clean Project Structure

## 🛠️ Technologies Used

- Python 3
- MySQL
- mysql-connector-python

## 📂 Project Structure

```
student-management-system/
│
├── main.py
├── config/
├── controllers/
├── database/
├── exceptions/
├── models/
├── repositories/
├── services/
├── tests/
├── utils/
└── validators/
```

## 🧠 Backend Architecture

```
User
   │
   ▼
Controller
   │
   ▼
Service
   │
   ▼
Repository
   │
   ▼
Database
```
